## 4. COLOR PALETTE

| Role | Hex | Usage |
|---|---|---|
| **Background** | `#0B1020` | Page background, dark sections |
| **Main Brand** | `#4F46E5` | Logo, section accents, active states |
| **CTA Buttons** | `#06B6D4` | Primary action buttons (cyan pop) |
| **Hover / Accent** | `#A855F7` | Hover states, highlights, gradients |
| **Primary Text** | `#F8FAFC` | Headings, body text |
| **Secondary Text** | `#94A3B8` | Subtext, captions, placeholders |

### Gradient (for hero/banner)
```css
background: linear-gradient(135deg, #4F46E5 0%, #06B6D4 50%, #A855F7 100%);
```

### Brand Aesthetic
Dark, futuristic, intelligent — a palette that signals **trust + technology + innovation**.
