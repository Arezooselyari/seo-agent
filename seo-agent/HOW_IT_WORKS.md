# سیستم ارزیابی مقالات — راهنمای نهایی (تست‌شده ✅)

این سیستم تست شد و کامل کار می‌کند. کل چرخه:

```
SEO-Agent مقاله تولید می‌کند (با نمره‌ی seo_grade)
        ↓
ارزیاب نمره را چک می‌کند
        ↓
   نمره ≥ ۹۰ ؟
   /          \
  بله          نه
   ↓            ↓
تلگرام      needs_review
(دکمه‌ها)   (در دیتابیس)
   ↓
شما کلیک می‌کنید (✅/❌)
   ↓
دیتابیس آپدیت می‌شود (approved/rejected)
```

## ⚙️ تنظیمات (آماده است)

توکن تلگرام از فایل اصلی پروژه (`D:\prjcluade\.env`) خوانده می‌شود — نیازی به کپی نیست.
- `TELEGRAM_BOT_TOKEN` ✅ موجود
- `TELEGRAM_CHAT_ID` ✅ موجود (70362663)
- آستانه‌ی تایید: ۹۰ (در `config/settings.yaml` قابل تغییر)

## 🚀 دستورهای اصلی

**همه‌ی دستورها باید از پوشه‌ی `D:\prjcluade\seo-agent` و با `PYTHONIOENCODING=utf-8` اجرا شوند.**

### ۱. ارزیابی + ارسال به تلگرام
```bash
cd D:\prjcluade\seo-agent
set PYTHONIOENCODING=utf-8
python -m src.evaluate_and_sync
```
مقالات pending را ارزیابی می‌کند؛ آن‌هایی با نمره ≥ ۹۰ را به تلگرام می‌فرستد؛ بقیه را `needs_review` می‌کند.

### ۲. پردازش کلیک‌های شما
```bash
python -m src.process_approvals
```
بعد از اینکه در تلگرام دکمه‌ها را زدید، این را اجرا کنید تا تصمیم‌ها در دیتابیس ثبت شوند.

### ۳. داشبورد وب (جایگزین تلگرام)
```bash
python -m src.web_server
```
سپس http://localhost:5000 — همه‌ی مقالات با دکمه‌های تایید/ردّ.

## 🔁 خودکارسازی (Task Scheduler)

دو Task بسازید (مثل بقیه‌ی پروژه که با bat اجرا می‌شوند):
1. **هر ساعت:** `python -m src.evaluate_and_sync` (ارسال مقالات جدید)
2. **هر ۵ دقیقه:** `python -m src.process_approvals` (ثبت کلیک‌های شما)

> نکته: روش «process_approvals هر چند دقیقه» از یک شنونده‌ی دائمی (run_polling)
> مطمئن‌تر است، چون اگر سیستم خاموش/روشن شود، کلیک‌های در صف تلگرام بعداً پردازش می‌شوند.

## 📁 فایل‌های سیستم

| فایل | کار |
|------|-----|
| `src/evaluator.py` | منطق ارزیابی (نمره ≥ ۹۰؟) |
| `src/evaluate_and_sync.py` | ارزیابی + ارسال به تلگرام |
| `src/telegram_approver.py` | ساخت پیام و دکمه‌ها |
| `src/process_approvals.py` | خواندن کلیک‌ها و آپدیت دیتابیس |
| `src/web_server.py` | داشبورد وب |

## 📊 وضعیت‌های مقاله در دیتابیس

| وضعیت | معنی |
|--------|------|
| `pending` | تازه تولید شده، منتظر ارزیابی |
| `approved` | تایید شده (نمره ≥ ۹۰ + کلیک شما) |
| `rejected` | ردّ شده توسط شما |
| `needs_review` | نمره < ۹۰، نیاز به بررسی دستی |
| `published` | منتشر شده |

## ✅ نتیجه‌ی تست (۲۹ ژوئن ۲۰۲۶)

- ✅ ارزیاب: نمره ۹۲/۹۴/۹۵ → approve، نمره ۷۵ → needs_review
- ✅ تلگرام: پیام با دکمه‌ها ارسال شد و دریافت شد
- ✅ کلیک: «approval_approve_4» از شما دریافت شد
- ✅ دیتابیس: مقاله #۴ → `approved` با timestamp
- ✅ داشبورد: API و دکمه‌ها کار کردند
